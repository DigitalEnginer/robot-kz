# robot-kz

Landing website for **ORDA ROBOTICS** — official supplier of Unitree and PUDU robots in Kazakhstan.

Сайт-витрина компании ORDA ROBOTICS — официального поставщика роботов Unitree и PUDU в Казахстане.

## Stack

- Vanilla JavaScript, HTML, CSS
- Serverless API (`/api`)
- Deployed on Vercel

## Structure

```
├── api/        # serverless endpoints
├── assets/     # images and media
├── config/     # site configuration
├── css/        # styles
├── js/         # client scripts
├── server/     # server utilities
├── tests/      # tests
└── index.html  # entry point
```

## Run locally

```bash
npm install
npx vercel dev
```
